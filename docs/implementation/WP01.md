## Deliverables

- [endpoints.json](contracts/endpoints.json): all 90 registered API routes, role/guard inventory, executed anonymous/public boundary fixtures, and existing functional suites. OPTIONS, legal pages and static/SPA surfaces are separately described. Successful participant/admin/partner responses are represented in the fixture corpus and existing suites; the anonymous matrix alone is not a complete permission test.

Tests assert numeric IDs, scrypt/bearer behavior, replay after tariff changes, altered-payload conflict, denied foreign access, parcel batches, durable failed-proof attempts, return-code privacy, cash confirmation and share revocation.
- [schema.json](contracts/schema.json): SQLite schema version 3, tables, columns, foreign keys, indexes and triggers. Capture used a new synthetic database, not a copy of customer data.
- [config.json](contracts/config.json), [money.json](contracts/money.json): SDK/runtime/source tariff defaults, setting units and literal fare/commission/night fixtures. No live deployment configuration was inspected or claimed. Preserve configured production tariffs through import/reconciliation; these defaults are not a substitute.
- [features.json](contracts/features.json): observed feature registry and separately labelled inactive prescribed pilot policy. Ride/freight are implemented but disabled unless configured in `WIND_ENABLED_SERVICES`; configuration is not permission to operate.
- [tests.json](contracts/tests.json): the 42 existing npm test entries, source fingerprints and optional test commands. Later source changes do not invalidate these input fingerprints.

## Data classification and access

| Data | Purpose/access | Retention/migration boundary |
|---|---|---|
| Password digests, bearer hashes, provider/partner credentials | Server-only authentication; never fixtures/client/public tracking | Preserve installed account/session formats; credentials remain external |
| Customer/driver contact and precise pickup/destination | Owner, assigned participant and authorized staff; pre-assignment/public views redact | Retain only for authorized service/history/support; future retention policy must preserve dispute/legal holds |
| Latest accepted driver fix | Current authorized assignment; public tracking receives its allowlisted projection | Latest fix only; no new raw trace history or preassignment collection in WP01 |
| Handover/return PIN and proof attempts | Customer/sender challenge; assigned driver submits proof; audit retained | Same original order/custody; sender return code stays hidden from driver/admin responses |
| Cash entries, commission snapshots, subscriptions and promotions | Role-scoped service and financial reconciliation | Exact integer cash values, immutable confirmed entries and existing obligation history preserved |
| Chat, complaints, safety and support records | Current participants or authorized staff; former assignment access denied | Preserve ownership/audit/recovery semantics; terminal return does not erase obligations |
| Public tracking token | Revocable bearer link to minimized allowlist | Rotation/revocation takes effect on resumed reads; never a general order/account credential |

Fixtures contain synthetic labels and redaction markers, never real people, phone numbers, session tokens, PINs or production locations.

## Rollout, rollback and limits

No runtime policy, API, account or database migration is changed by this packet. Baseline tests use temporary synthetic SQLite and loopback HTTP. No production data, field routing corpus, carrier, payment, Azure restore or physical-device evidence was required or fabricated. The baseline permits WP02 engineering; it does not authorize a production cutover. Later packets reference this corpus, preserve legacy fields and outcomes, and review additive schema/response changes explicitly.

Implementation was recovered from a rate-limited baseline agent's completed artifacts; the missing result record and deterministic pricing correction were completed and independently verified by the parent. No commit, push or deployment was performed.
