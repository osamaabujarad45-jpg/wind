# WP17: later capability activation gates

WP17 depends on the completed controlled WP16 pilot, not source merge. No WP16 completion evidence is recorded here. Every capability below remains **OFF** pending the pilot and its own evidence. OFF refers to the later capability, not removal of existing services. The register records requirements; it does not implement or activate them. Owners are the accountable roles from the launch gate register; each change also requires an independent reviewer.

For each capability, completion also requires a complete command/event/schema contract, failure table, independent tests, telemetry, measured shadow result, controlled feature-flag rollout and reversible application change. Flipping any flag without its named evidence and independent review is a release blocker. A failed gate leaves the affected capability off and deployment unapproved.
